# CompTIA Security+ (SY0-701) Alignment

This project supports learning and practical discussion across the five Security+
domains. It is not a complete Security+ curriculum, certification, or proof of
professional competence in every objective.

| Security+ domain | Related lab work | Scope and limitation |
|---|---|---|
| 1.0 General Security Concepts | Confidentiality, integrity, availability, least privilege, human oversight, defence in depth | Concepts applied to a fictional AI assistant and governance scenario |
| 2.0 Threats, Vulnerabilities, and Mitigations | Direct/indirect prompt injection, jailbreak attempts, data leakage, STRIDE threat model, mitigations | AI-specific attack simulation; not a full vulnerability assessment |
| 3.0 Security Architecture | Secure AI architecture, trust boundaries, tool broker, restricted permissions, logging | Conceptual architecture and local proof-of-concept |
| 4.0 Security Operations | Detection scripts, synthetic event logs, incident response playbook, evidence review | Offline/synthetic detection; not production SIEM deployment |
| 5.0 Security Program Management and Oversight | AI inventory, risk register, vendor due diligence, acceptable-use policy, ISO/IEC 42001 and Google SAIF mapping | Governance templates for a fictional SME; not an audit or certification |

## Evidence boundary

The project demonstrates selected concepts and hands-on exercises that relate to
these domains. It does not claim full coverage of every CompTIA objective or replace
the official exam objectives, study materials, or practical experience.
